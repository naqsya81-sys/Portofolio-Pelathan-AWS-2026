# Pages

Portofolio ini adalah **single-page application statis** — satu halaman yang
digulir dari atas ke bawah, dengan navigasi atas yang melompat ke setiap bagian.

Halaman utama ada di `../index.html`. "Halaman" secara logis dipetakan ke
section berikut (dapat diakses lewat anchor):

| Section       | Anchor         | Deskripsi                          |
| ------------- | -------------- | ---------------------------------- |
| Beranda       | `#home`        | Hero + animasi + CTA               |
| Tentang       | `#about`       | Profil singkat + statistik         |
| Keahlian      | `#skills`      | Kartu skill + bar kemahiran        |
| Proyek        | `#projects`    | Grid proyek unggulan               |
| Pengalaman    | `#experience`  | Timeline karier                    |
| Kontak        | `#contact`     | Info kontak + form (mailto)        |

Jika di masa depan ingin menambah halaman terpisah (mis. `blog.html`),
letakkan di folder ini dan tautkan dari navbar.
