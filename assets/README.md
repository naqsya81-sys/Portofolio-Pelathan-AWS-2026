# Assets

Aset statis untuk portofolio.

```
assets/
├── css/
│   ├── base.css          # Design tokens, reset, typografi, utilitas
│   ├── components.css    # Komponen UI (tombol, navbar, kartu, form)
│   ├── layout.css        # Tata letak tiap section
│   ├── animations.css    # Keyframes, reveal, background aurora
│   └── responsive.css    # Breakpoint mobile / tablet / desktop
├── js/
│   └── main.js           # Semua interaktivitas sisi klien
└── img/                  # (opsional) gambar, favicon, dsb.
```

Font dimuat dari Google Fonts: **Space Grotesk** (judul),
**Inter** (teks), dan **JetBrains Mono** (kode). Ikon sosial memakai inline SVG,
jadi tidak ada dependensi ikon eksternal.
